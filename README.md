Bartr is a community-driven local bartering platform that allows users to trade items nearby without using money.

## 🛠 App Overview

Bartr helps users:
- List items by uploading images from the photo library or camera
- Discover nearby listings using location-based search
- Chat in real time to negotiate and finalize trades
- Receive notifications for messages and trade updates
- Build trust through user profiles and ratings

---

## 🔐 Privacy & Permissions

Bartr only requests permissions that are required for core app functionality:

- **Location (While in Use)**  
  Used to show nearby item listings and local traders.

- **Photo Library & File Access**  
  Used when users upload images for listings or profiles.

- **Camera**  
  Used to capture photos for item listings and user profiles.

- **Notifications**  
  Used to deliver chat messages and trade status updates.

- **Microphone (Android only)**  
  Present for future communication features and not actively used in the current version.

No permissions are accessed in the background without user action.

---

## 🔒 Data & Security

Bartr does not support payments or real-money transactions.  
All user data is handled securely and only used to provide core app functionality.

For any privacy-related questions, please contact us via the support email above.
